# 前端样式规则清单

只有规则，没有解释和示例。要示例看 [brief.md](brief.md)，要理由看 [full.md](full.md)。

1. 预处理器 less / scss 二选一，同一项目内不混用。
2. 有组件库的项目不引入 tailwind。
3. 页面组件样式一律用 CSS Module，文件名与组件同名。
4. Module 内类名用 camelCase。
5. 页面 module 只写布局和页面独有样式，不写公共组件内部样式。
6. 公共组件禁止使用 CSS Module；内部类名全局，带项目前缀，用 BEM。
7. 公共组件根元素必须带组件级类名，作为唯一对外样式入口。
8. 外部调整时，在使用方页面的 module 里用 `:global` 穿透。
9. 穿透只允许改表现属性（颜色、字号、间距、圆角），不允许改布局结构。
10. 重封装组件库组件时根元素带前缀类名；禁止直接改第三方内部 class。
11. 改样式只允许三种手段，按优先级：theme token → 重封装 → 页面穿透。
12. 全局样式只允许一个文件；组件里禁止 import 全局 css。
13. design token 集中在 `:root` 变量或主题配置里；组件内禁止写死颜色值。
14. 嵌套不超过 3 层；`!important` 只用于覆盖第三方，且必须注释原因。
15. 状态类名统一用 `is-` 前缀：`is-active` / `is-disabled` / `is-loading` / `is-error`。
16. 禁止行内 `style`，动态计算值除外。
17. 公共组件文件头必须声明"可覆盖的类名"。
18. 断点集中定义，页面里禁止裸写媒体查询数值。
19. 间距默认取 4 的倍数；无法满足时取偶数；因 1px 边框只能取奇数时，优先改用 flex 居中解决。
20. 样式里不写魔法数字，间距走变量或 4 的倍数。
21. 单个 module 文件超过 150 行，考虑拆组件。
