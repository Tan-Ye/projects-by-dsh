# Python 规则清单

只有规则，没有解释和示例。要示例看 [brief.md](brief.md)，要理由看 [full.md](full.md)。

1. 数据库行的类型用 `TypedDict` 描述，不用 `dataclass`。
2. 数据库查询必须显式列名，禁止 `SELECT *`。
3. 领域对象命中任一条件才用 `dataclass`：需要构造时校验 / 有业务不变量 / 有行为。
4. 函数签名 100% 标注参数和返回值。
5. 变量只在需要"定死类型"的地方标注；循环变量、临时值不标。
6. 编辑器类型检查必须常开（如 Pylance `basic` 及以上）。
7. 函数的"是什么"写在 `docstring` 里。
8. `#` 注释只写"为什么这么写"。
9. `cast` 必须紧跟一行注释，说明为什么可以保证。
10. 类型就近声明：定义在使用它的文件里；同时满足「被 2 个以上模块使用」和「不属于任何单一来源」才提升到公共模块。
11. 拆分判据看两样：实现行数、**类型声明占的篇幅**。两者任一过重就按来源拆（如 `fin_models.py`），不建全局 `models.py`、`types.py`。
